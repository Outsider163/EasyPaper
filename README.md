# EasyPaper

EasyPaper 是一个学术论文分区浏览器扩展。它会在中国知网和 Google Scholar 的检索结果中自动识别论文来源，自动更新公开目录，并在页面上直接显示 CCF、学校分级及用户自定义的中科院升级版、JCR、新锐分区、影响因子、SJR 等标签。

当前版本内置 CCF 第七版目录和《云南财经大学学术期刊分级标准与目录（2026）》，同时支持通过 CSV、TSV 或 JSON 补充中科院分区、影响因子及其他学校等级。

> 当前版本为 `0.3.0`，主要面向本地安装与功能验证。

## 功能特性

- 自动识别中国知网检索结果页和论文详情页中的来源期刊；
- 自动识别 Google Scholar 检索结果中的期刊或会议；
- 显示 CCF A、B、C 类标签；
- 显示云南财经大学权威、A、B、C、D 级标签；
- 同一来源命中多个目录时并列显示多个标签；
- 新安装后自动下载并缓存在线公开目录，每 12 小时最多检查一次；
- 在线目录使用版本清单、记录数、字节数和 SHA256 四重校验，失败时保留现有数据；
- 旧版本已有手动目录时自动保护，不会被后台更新覆盖；
- 设置页支持查看在线目录版本、来源、数量、安装时间，并可立即更新；
- 支持上传本地 CSV、TSV、JSON 目录；
- 自定义目录支持中科院升级版大类/小类、JCR 学科 Q区、CCF、影响因子、学校等级、ISSN、别名和简称；
- 支持新锐大类/小类 1–4 区、Top 期刊与 Top 会议标签；
- 支持 SCIE、SSCI、ESCI、AHCI、Scopus、OAJ 等检索标签；
- 支持 SJR 数值、SJR 最佳 Q区和 H-index 标签；
- 支持 Review、Data Journal、Under Review 和目录附加标注；
- 将中科院升级版、JCR 与新锐分别标识，不把 JCR Q1 冒充“SCI 基础版 1区”；
- 采用精确名称、受控别名和简称匹配，遇到截断或歧义来源时不猜测等级；
- 在线公开目录从 EasyPaper GitHub 仓库下载，并在浏览器本地缓存；
- 用户手动上传的文件仍只在浏览器本地解析和保存，不发送到服务器。

## 内置目录

### CCF 第七版（2026 年）

- PDF 原始目录包含 681 个期刊/会议行；
- 合并 4 个跨学科重复收录项后，共 677 个唯一来源；
- 覆盖 10 个计算机学科方向；
- 支持期刊和会议 A、B、C 类识别。

### 云南财经大学（2026 年）

- 附录共收录 992 个来源；
- 权威级 118 个、A 级 402 个、B 级 472 个；
- 根据学校正文规则，未在附录中获得更高等级的 CCF A/B 类来源显示为学校 C 级，CCF C 类来源显示为学校 D 级；
- 同一来源存在多个认定等级时采用较高等级。

两个目录合并并消除可验证的标点、长短刊名重复项后，EasyPaper 当前内置 1,563 个唯一来源。

云南财经大学标准中的其他 C、D、E 级条件可能依赖论文发表年份对应的 CSSCI、CSCD、SCIE、SSCI、EI 等外部数据库版本。EasyPaper 不会在缺少相应年度目录时仅凭名称推测这些等级。

## 安装

### 方式一：下载测试版

1. 从 [GitHub Releases](https://github.com/Outsider163/EasyPaper/releases/latest) 下载 `easypaper-0.3.0-chrome.zip`；
2. 将 ZIP 解压到一个固定目录；
3. 在 Chrome 地址栏打开 `chrome://extensions/`；
4. 打开右上角的“开发者模式”；
5. 点击“加载已解压的扩展程序”；
6. 选择刚才解压得到的目录。

不要直接选择 ZIP 文件，Chrome 需要加载解压后的目录。

### 方式二：从源码构建

需要先安装 Node.js 和 npm，推荐使用当前长期支持版本。

```bash
git clone https://github.com/Outsider163/EasyPaper.git
cd EasyPaper
npm install
npm run build
```

构建完成后：

1. 在 Chrome 地址栏打开 `chrome://extensions/`；
2. 打开右上角的“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择项目中的 `.output/chrome-mv3` 目录；
5. 打开中国知网或 Google Scholar 页面进行测试。

修改源码并重新构建后，只需在扩展管理页点击 EasyPaper 卡片上的刷新按钮，然后刷新论文页面。

## 使用方法

1. 安装并启用 EasyPaper；
2. 打开中国知网检索结果页、论文详情页或 Google Scholar；
3. EasyPaper 会读取页面中的来源期刊或会议名称；
4. 匹配成功后，标签会显示在论文信息附近。

常见标签包括：

- `CCF A`
- `云南财经大学 A`
- `中科院 1区`
- `SCI升级版 计算机科学 1区`
- `JCR 计算机：信息系统 Q1（1/266）`
- `IF 8.5（2025）`
- `SJR Q1`

如果页面来源文字被截断、目录没有该来源，或一个简称对应多个出版物，EasyPaper 只显示来源标签，不会强行添加等级。

## 在线公开目录

EasyPaper v0.3.0 默认从仓库中的 `catalog/manifest.json` 获取在线目录清单，并下载 `catalog/public-catalog.csv`。首次安装会自动启用在线更新；以后由后台定时检查。用户也可以在“扩展设置 → 在线公开目录”中立即更新或关闭自动更新。

当前在线公开目录包含 CCF 第七版和云南财经大学 2026 核心目录，共 1,563 条。中科院、JCR、新锐、SJR 等授权不明确的全量数据不会擅自公开，仍可通过本地文件导入。

## 导入自定义目录

点击浏览器工具栏中的 EasyPaper 图标，然后打开“扩展设置”。在“当前补充目录与本地导入”中可以：

- 选择 CSV、TSV 或 JSON 文件；
- 下载 CSV 模板；
- 导入并替换当前自定义目录；
- 查看前 50 条数据预览；
- 清空已上传目录。

文件最大为 15 MB，最多可包含 30,000 条记录。CSV 示例：

```csv
期刊名称,类型,别名,简称,ISSN,中科院分区,中科院版本,中科院升级版标签,JCR分区标签,CCF级别,影响因子,影响因子年份,新锐分区标签,新锐版本,检索标签,SJR标签,学校等级,学校名称
示例期刊,期刊,Example Journal|示例学报,EJ,1234-567X,2区,2025,计算机科学 2区|计算机科学 TOP,计算机：信息系统 Q1（1/266）,B,4.2,2025,计算机科学 1区|计算机科学 TOP,2026,SCIE|Scopus,SJR 3.2（2025）|SJR Q1|H-index 120,A,示例大学
```

支持的主要字段：

| 字段 | 说明 |
| --- | --- |
| 期刊名称 | 必填，期刊或会议的标准名称 |
| 类型 | `期刊` 或 `会议`，未填写时默认为期刊 |
| 别名 | 多个值使用 `\|` 分隔 |
| 简称 | 例如 `TPAMI`、`CVPR` |
| ISSN | 期刊 ISSN，可填写多个值 |
| 中科院分区 | 支持 1–4 区 |
| 中科院学科标签 | 例如 `计算机科学 1区`，多个值用 `\|` 分隔 |
| 中科院升级版标签 | 例如 `计算机科学 1区`、`计算机科学 TOP`，显示时带 `SCI升级版` 前缀 |
| JCR分区标签 | 例如 `计算机：信息系统 Q1（1/266）` |
| 新锐分区标签 | 例如 `计算机科学 1区`、`计算机科学 TOP` |
| 新锐版本 | 新锐目录的四位年份 |
| 检索标签 | 例如 SCIE、SSCI、ESCI、AHCI、Scopus、OAJ |
| SJR标签 | 例如 `SJR 3.2（2025）`、`SJR Q1`、`H-index 120` |
| 期刊类型标签 | 例如 Review、Report、Data Journal |
| 预警标签 | 例如 Under Review |
| 其他标签 | 例如中国期刊支持计划 |
| CCF级别 | 支持 A、B、C |
| 影响因子 | 必须同时提供四位年份 |
| 学校等级 | 可填写学校自己的等级名称 |
| 学校名称 | 学校标签中显示的名称 |

自定义数据保存在 `browser.storage.local`，并申请 `unlimitedStorage` 以容纳大型本地目录。开关设置使用浏览器同步存储；EasyPaper 没有后端服务，也不会上传目录文件。

## 数据与准确性说明

- 等级目录可能随官方版本更新，请在重要用途下同时核对对应机构发布的正式目录；
- EasyPaper 只在来源名称精确命中时显示等级，不根据论文题目或作者推测来源；
- CCF 中同名但分别属于期刊和会议的条目会保留为歧义，不会自动选择其中一个；
- 影响因子具有年份属性，自定义目录必须同时填写数值和数据年份；
- EI 仅在导入数据明确包含 EI/Compendex 字段时显示；当前本地数据没有该字段，因此不会猜测“EI 检索”；
- JCR Q区与中科院升级版是不同体系，EasyPaper 会分别显示；
- 在线公开目录目前只包含仓库已内置的 CCF 与云南财经大学核心目录；
- 完整的中科院分区与 JCR 影响因子目录不随仓库发布；请仅导入自己合法取得且有权使用的数据，不要将受许可限制的数据公开上传；
- 本仓库不包含用于数据提取的原始 PDF、个人学习文档或本地构建产物。

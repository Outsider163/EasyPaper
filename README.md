# EasyPaper

EasyPaper 是一个学术论文分区浏览器扩展。它会在中国知网和 Google Scholar 的检索结果中自动识别论文来源，从 GitHub 数据服务器自动更新目录，并在页面上直接显示国际 CCF A/B/C、CCF 中文 T1/T2/T3、学校分级、中科院升级版、JCR、新锐分区、北大中文核心、CSSCI 来源/扩展版、中国科技核心、CSCD 核心/扩展库、中国科协高质量期刊、影响因子、SJR 等标签。

当前版本内置 CCF 第七版目录和《云南财经大学学术期刊分级标准与目录（2026）》，支持服务器全量目录，也支持通过 CSV、TSV 或 JSON 补充自己的数据。

> 当前版本为 `0.6.3`，新增 CCF 2025 国内期刊 T1/T2/T3 推荐标签，并与国际 CCF A/B/C、中国科协高质量期刊标签分别显示。

## 功能特性

- 自动识别中国知网检索结果页和论文详情页中的来源期刊；
- 自动识别 Google Scholar 检索结果中的期刊或会议；
- 显示 `CCF-A 类推荐`、`CCF-B 类推荐`、`CCF-C 类推荐` 标签；
- 显示 `CCF 中文 T1 推荐`、`CCF 中文 T2 推荐`、`CCF 中文 T3 推荐` 标签；
- 自定义或在线目录明确提供时，显示北大中文核心、CSSCI 来源/扩展版、中国科技核心、CSCD 核心/扩展库和中国科协高质量期刊标签；
- 显示云南财经大学权威、A、B、C、D 级标签；
- 同一来源命中多个目录时并列显示多个标签；
- 新安装后自动下载并缓存在线服务器目录，每 12 小时最多检查一次；
- 在线目录使用版本清单、记录数、字节数和 SHA256 四重校验，失败时保留现有数据；
- 旧版本已有手动目录时自动保护，不会被后台更新覆盖；
- 设置页支持查看在线目录版本、来源、数量、安装时间，并可立即更新；
- 支持上传本地 CSV、TSV、JSON 目录；
- 支持一键导出当前全标签目录，用于备份或交给仓库维护者发布；
- 自定义目录支持中科院升级版大类/小类、JCR 学科 Q区、国际 CCF、CCF 中文、北大/CSSCI/科技核心/CSCD/中国科协、影响因子、学校等级、ISSN、别名和简称；
- 支持新锐大类/小类 1–4 区、Top 期刊与 Top 会议标签；
- 支持 SCIE、SSCI、ESCI、AHCI、Scopus、OAJ 等检索标签；
- 支持 SJR 数值、SJR 最佳 Q区和 H-index 标签；
- 支持 Review、Data Journal、Under Review 和目录附加标注；
- 将中科院升级版、JCR 与新锐分别标识，不把 JCR Q1 冒充“SCI 基础版 1区”；
- 采用精确名称、受控别名和简称匹配，遇到截断或歧义来源时不猜测等级；
- 在线服务器目录从 EasyPaper GitHub 仓库下载，并在浏览器本地缓存；
- 用户手动上传的文件仍只在浏览器本地解析和保存，不发送到服务器。

## 内置与在线目录

### CCF 第七版（2026 年）

- PDF 原始目录包含 681 个期刊/会议行；
- 合并 4 个跨学科重复收录项后，共 677 个唯一来源；
- 覆盖 10 个计算机学科方向；
- 支持期刊和会议识别，等级显示为 CCF-A 类推荐、CCF-B 类推荐、CCF-C 类推荐。

### CCF 计算领域高质量科技期刊（2025）

- 共收录 68 本国内期刊，其中 T1 19 本、T2 22 本、T3 27 本；
- 中文刊名作为标准名称，目录提供的英文刊名同时作为匹配别名；
- 页面显示为 `CCF 中文 T1/T2/T3 推荐`；
- 该目录与国际 CCF A/B/C、中国科协高质量科技期刊分级目录属于不同评价体系，EasyPaper 会分别显示，命中多个体系时并列展示。

### 云南财经大学（2026 年）

- 附录共收录 992 个来源；
- 权威级 118 个、A 级 402 个、B 级 472 个；
- 根据学校正文规则，未在附录中获得更高等级的 CCF A/B 类来源显示为学校 C 级，CCF C 类来源显示为学校 D 级；
- 同一来源存在多个认定等级时采用较高等级。

两个内置目录合并并消除可验证的标点、长短刊名重复项后，EasyPaper 当前内置 1,563 个唯一来源。

云南财经大学标准中的其他 C、D、E 级条件可能依赖论文发表年份对应的 CSSCI、CSCD、SCIE、SSCI、EI 等外部数据库版本。EasyPaper 不会在缺少相应年度目录时仅凭名称推测这些等级。

## 安装

### 方式一：下载测试版

1. 从 [GitHub Releases](https://github.com/Outsider163/EasyPaper/releases/latest) 下载 `easypaper-0.6.3-chrome.zip`；
2. 将 ZIP 解压到一个固定目录；
3. 在 Chrome 地址栏打开 `chrome://extensions/`；
4. 打开右上角的“开发者模式”；
5. 点击“加载已解压的扩展程序”；
6. 选择刚才解压得到的目录。

不要直接选择 ZIP 文件，Chrome 需要加载解压后的目录。

### 方式二：从源码构建

需要先安装 Node.js 和 npm，推荐使用当前长期支持版本。

```bash
git clone https://github.com/Outsider163/EasyPaper.git
cd EasyPaper
npm install
npm run build
```

构建完成后：

1. 在 Chrome 地址栏打开 `chrome://extensions/`；
2. 打开右上角的“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择项目中的 `.output/chrome-mv3` 目录；
5. 打开中国知网或 Google Scholar 页面进行测试。

修改源码并重新构建后，只需在扩展管理页点击 EasyPaper 卡片上的刷新按钮，然后刷新论文页面。

## 使用方法

1. 安装并启用 EasyPaper；
2. 打开中国知网检索结果页、论文详情页或 Google Scholar；
3. EasyPaper 会读取页面中的来源期刊或会议名称；
4. 匹配成功后，标签会显示在论文信息附近。

常见标签包括：

- `CCF-A 类推荐`
- `CCF-B 类推荐`
- `CCF-C 类推荐`
- `CCF 中文 T1 推荐`
- `CCF 中文 T2 推荐`
- `CCF 中文 T3 推荐`
- `北大中文核心`
- `南大中文核心`
- `CSSCI扩展版 2025-2026`
- `中国科技核心 2025`
- `CSCD核心库 2025-2026`
- `CSCD扩展库 2025-2026`
- `中国科协 信息通信 T1（2025总汇）`
- `云南财经大学 A`
- `中科院 1区`
- `SCI升级版 计算机科学 1区`
- `JCR 计算机：信息系统 Q1（1/266）`
- `IF 8.5（2025）`
- `SJR Q1`

如果页面来源文字被截断、目录没有该来源，或一个简称对应多个出版物，EasyPaper 只显示来源标签，不会强行添加等级。

## 在线服务器目录

EasyPaper v0.6.3 使用 GitHub 仓库作为静态数据服务器：先读取 `catalog/manifest.json`，再下载 `catalog/public-catalog.csv`。首次安装和从旧版升级时会立即获取最新目录，以后每 12 小时最多检查一次；用户手动导入的目录仍不会被覆盖。用户也可以在“扩展设置 → 在线服务器目录”中立即更新或关闭自动更新。

清单包含目录版本、生成时间、记录数、字节数和 SHA256。任一校验失败时，插件会保留浏览器中的现有数据。当前服务器目录为 8,184 条合并记录；已安装的浏览器会自动切换到新版本，无需重新安装扩展。

数据来源、版本指纹、数量核验和中国科协暂未发布学科见 [`catalog/sources/README.md`](catalog/sources/README.md)。

## 导入自定义目录

点击浏览器工具栏中的 EasyPaper 图标，然后打开“扩展设置”。在“当前补充目录与本地导入”中可以：

- 选择 CSV、TSV 或 JSON 文件；
- 下载 CSV 模板；
- 导出当前全标签 CSV；
- 导入并替换当前自定义目录；
- 查看前 50 条数据预览；
- 清空已上传目录。

文件最大为 15 MB，最多可包含 30,000 条记录。CSV 示例：

```csv
期刊名称,类型,别名,简称,ISSN,CCF级别,CCF中文期刊标签,CCF中文期刊版本,北大中文核心标签,南大中文核心标签,CSSCI扩展版标签,中国科技核心标签,CSCD核心库标签,CSCD扩展库标签,中国科协高质量期刊标签
示例期刊,期刊,Example Journal|示例学报,EJ,1234-567X,B,T2,2025,2023版,CSSCI,2025-2026,2025,2025-2026,,计算机 T1（2025总汇）
```

支持的主要字段：

| 字段 | 说明 |
| --- | --- |
| 期刊名称 | 必填，期刊或会议的标准名称 |
| 类型 | `期刊` 或 `会议`，未填写时默认为期刊 |
| 别名 | 多个值使用 `\|` 分隔 |
| 简称 | 例如 `TPAMI`、`CVPR` |
| ISSN | 期刊 ISSN，可填写多个值 |
| CCF中文期刊标签 | 支持 `T1`、`T2`、`T3`，显示为 CCF 中文推荐标签 |
| CCF中文期刊版本 | 对应目录年份，例如 `2025` |
| 中科院分区 | 支持 1–4 区 |
| 中科院学科标签 | 例如 `计算机科学 1区`，多个值用 `\|` 分隔 |
| 中科院升级版标签 | 例如 `计算机科学 1区`、`计算机科学 TOP`，显示时带 `SCI升级版` 前缀 |
| JCR分区标签 | 例如 `计算机：信息系统 Q1（1/266）` |
| 新锐分区标签 | 例如 `计算机科学 1区`、`计算机科学 TOP` |
| 新锐版本 | 新锐目录的四位年份 |
| 检索标签 | 例如 SCIE、SSCI、ESCI、AHCI、Scopus、OAJ |
| 北大中文核心标签 | 填写“是”“收录”或目录版本，例如 `2023版`；仅在明确收录时显示 |
| 南大中文核心标签 | CSSCI 收录标记；可填写 `CSSCI` 或目录版本 |
| CSSCI扩展版标签 | CSSCI 扩展版收录标记，例如 `2025-2026` |
| 中国科技核心标签 | CSTPCD 收录标记；可填写“收录”或目录版本 |
| CSCD核心库标签 | CSCD 核心库收录标记，例如 `2025-2026` |
| CSCD扩展库标签 | CSCD 扩展库收录标记，例如 `2025-2026` |
| 中国科协高质量期刊标签 | 学科与等级，例如 `计算机 T1（2025总汇）` |
| SJR标签 | 例如 `SJR 3.2（2025）`、`SJR Q1`、`H-index 120` |
| 期刊类型标签 | 例如 Review、Report、Data Journal |
| 预警标签 | 例如 Under Review |
| 其他标签 | 例如中国期刊支持计划 |
| CCF级别 | 支持 A、B、C，页面显示为 CCF-A 类推荐、CCF-B 类推荐、CCF-C 类推荐 |
| 影响因子 | 必须同时提供四位年份 |
| 学校等级 | 可填写学校自己的等级名称 |
| 学校名称 | 学校标签中显示的名称 |

自定义数据保存在 `browser.storage.local`，并申请 `unlimitedStorage` 以容纳大型本地目录。手动文件不会由浏览器自动上传；在线目录从 GitHub 数据服务器下载。

## 开发

```bash
# 启动 Chrome 开发模式
npm run dev

# 重建 1,563 条核心目录和清单
npm run catalog:build


# 从导出的全标签文件发布服务器目录
npm run catalog:publish -- "EasyPaper-全标签-2026.csv" 2026-full.1 "EasyPaper 2026 全量目录"

# 校验服务器目录的记录数、大小和 SHA256
npm run catalog:verify

# 运行测试
npm test

# TypeScript 静态检查
npm run compile

# 构建 Chrome MV3 扩展
npm run build

# 构建 Firefox 版本
npm run build:firefox
```

- 截断、冲突和重复 ID 等安全边界；
- 用户目录导入与字段校验；
- CCF 与云南财经大学目录数量和代表性条目；
- CCF 2025 国内期刊目录 68 条、T1/T2/T3 数量和中英文名称匹配；

## 数据与准确性说明

- 等级目录可能随官方版本更新，请在重要用途下同时核对对应机构发布的正式目录；
- EasyPaper 只在来源名称精确命中时显示等级，不根据论文题目或作者推测来源；
- CCF 中同名但分别属于期刊和会议的条目会保留为歧义，不会自动选择其中一个；
- 影响因子具有年份属性，自定义目录必须同时填写数值和数据年份；
- EI 仅在导入数据明确包含 EI/Compendex 字段时显示；当前本地数据没有该字段，因此不会猜测“EI 检索”；
- JCR Q区与中科院升级版是不同体系，EasyPaper 会分别显示；
- 北大中文核心、CSSCI、CSTPCD、CSCD 和中国科协标签仅在在线或导入目录明确标明收录时显示；
- 在线目录可以包含全部标签；仓库维护者应确保上传数据拥有公开再分发权限；
- 本仓库不包含用于数据提取的原始 PDF、个人学习文档或本地构建产物。

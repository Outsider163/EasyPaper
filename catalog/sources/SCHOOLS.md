# 三所学校的期刊等级

云南财经大学沿用已有 2026 目录。本次新增东北财经大学和西南财经大学 2025 年修订目录，设置显示全称，页面简称分别为云财、东财、西财。各校等级相互独立。

## 来源和范围

- 东北财经大学：用户提供的《东北财经大学高水平学术期刊目录.pdf》，32 页。中文编号 1–378，另有 6 本明确列出的 D 级刊物；外文编号 1–795。提取 1179 行明确条目。修订年份为 2025，正文注明 2026-01-01 起施行。
  SHA-256：`3a12bb64d73f07fa23dca4fcfe9e6cad62b37819149b072f78c9e06a14896297`
- 西南财经大学：用户提供的同名学校目录 PDF，27 页。中文编号 1–97；外文编号 1–561，其中 560、561 为 Nature / Science 其他子刊的概括性规则。提取 656 行明确条目，跨学科重复刊物合并，保留不同等级并标记“按学科”。
  SHA-256：`5a138d8d2779f90211da27463a89dda0ba45a8a4d31dc3c675b74ebc879a07dd`

`school-journals-2025.json` 保存原始刊名、页码、序号、学校、等级、ISSN 和规则；西财同时保留学科。`school-merge-report.json` 保存匹配结果和 ISSN 冲突记录。

本次导入明确列出的期刊等级。东财按检索库自动认定 D 级的条款、其他正式期刊条款，以及西财 Nature / Science 其他子刊条款，仅保留在来源记录中，不用模糊刊名自动套用。东财关于预警、文章类型及学校重新认定等条件仍应由使用者结合原文核实；标签表示目录等级，不代表每篇文章最终认定结果。

## 合并方法

优先使用明确刊名，再用唯一主 ISSN 匹配。对冲突 ISSN 不覆盖既有识别信息。仅标点、空格不同的既有记录保留各自身份并赋予一致等级；少数明确的简称、长标题映射在脚本中逐项列出。因而编译条目数量不同于原 PDF 的期刊数量。

多学校数据使用 `schools` 数组；原 `school` 字段继续兼容旧版本。CSV 新增尾列“多学校等级”，其中使用 JSON 保存学校全称、等级和版本。旧版缓存加载时仍保留新增内置学校等级。

## 重建

1. 将两份原始 PDF 放在 `tmp/sources/`，运行 `scripts/extract-school-pdfs.py`（依赖 pdfplumber）。
2. 运行 `npm exec vite-node scripts/merge-school-catalogs.ts`，生成学校内置数据及 `with-school-catalogs.csv`。
3. 运行 `npm run catalog:publish -- catalog/sources/with-school-catalogs.csv <新目录版本>`，生成本地发布文件。
4. 运行 `npm run catalog:verify`、`npm run compile`、`npm test`、`npm run build`。

公开目录当前本地版本为 `2025-2026-full.8`，共 9060 条。生成本地文件不等于已发布远程更新。原始 PDF 与个人学习文档保持本地。

# EasyPaper 中文期刊目录数据说明

本目录保存从正式目录整理得到的可发布 CSV、统计报告和来源校验信息。浏览器实际下载的是上一级目录中的 `public-catalog.csv`。

## 当前数据集

- 生成文件：`chinese-journal-labels-2025-2026.csv`
- 合并后期刊记录：7,184 条
- 北大中文核心：1,986 条匹配记录（2023 版）
- CSSCI 来源期刊：674 条匹配记录（2025—2026）
- CSSCI 扩展版：261 条匹配记录（2025—2026）
- 中国科技核心：2,740 条匹配记录（含 2025 年普通卷和科普卷）
- CSCD 核心库：1,111 条匹配记录（2025—2026）
- CSCD 扩展库：384 条匹配记录（2025—2026）
- 中国科协高质量期刊：4,922 条匹配记录，覆盖 42 个已通过数量核验的学科

同一期刊可能在原目录中重复出现，合并后匹配记录数会小于原始行数。合并使用标准名称、可靠别名和 ISSN；一个期刊可同时保留多个目录标签。

## 中国科协目录的发布门槛

中国科协 PDF 包含多种跨页、合并单元格和分级标题版式。仅当一个学科的提取数量与总目录公布数量完全一致时，才纳入在线目录。42 个学科已通过该门槛；另排除了 35 条名称明显在换页处截断的记录。

以下 17 个学科尚未纳入，详细的期望数与提取数见 `chinese-journal-labels-2025-2026.report.json`：地球科学、机械工程、建筑科学、地理资源、材料失效与保护、汽车工程、数学、材料-综合、振动工程、岩土力学与工程地质、舰船科学、光学工程和光学、管理科学、图像图形、遥感科学与技术、土壤学、药学。

## 发布校验

发布脚本会再次验证 CSV 可解析性、同类型名称唯一性、记录数、文件大小和 SHA256。生成后的全量服务器目录还会在本地实际激活一次，以检查别名冲突；任一检查失败都不应上传。

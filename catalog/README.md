# EasyPaper 在线公开目录

该目录由 EasyPaper 已内置的 CCF 第七版与《云南财经大学学术期刊分级标准与目录（2026）》生成，用于验证和提供在线目录自动更新能力。

- `manifest.json`：目录版本、生成时间、下载地址、记录数、字节数和 SHA256；
- `public-catalog.csv`：公开核心目录数据；
- 插件下载后会校验文件大小、记录数和 SHA256，校验失败时保留浏览器中的已有目录；
- 生成命令：`npm run catalog:build`。

本目录不包含中科院分区、JCR 影响因子、新锐分区或 SCImago/SJR 全量数据。此类数据只有在确认许可允许公开再分发后才会加入在线目录。
